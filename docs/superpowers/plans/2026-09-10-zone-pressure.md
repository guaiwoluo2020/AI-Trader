# 区域攻防与动量转换实施计划

目标：把已批准的“区域—攻防—方向—执行”设计接入现有结构分析。
技术：Python、MySQL 计划消费记录、磁盘结构快照、Vue/ECharts。

- [ ] 新建纯函数区域状态机：已收盘数据、ATR 分档、密集区与枢轴区域、独立访问、快跌/弱反弹、双向镜像事件。
- [ ] 将状态保存在结构快照；以时间戳作为身份，增量与从头回放同结果；配置变化另起状态版本。
- [ ] 新增 pressure_reversal / pressure_zone_breakout 计划；锁定区域和事件版本、真实结构目标、价格区间及失效条件。
- [ ] 接入公共配置与品种周期覆盖、页面区域和事件详情；高周期输入只使用已收盘K线。
- [ ] 账户执行侧验证阶段消费、成交回执、保护止损、风险预算及手数；同一机会不能重复首次开仓。
- [ ] 验证镜像、无前视、快照恢复、计划风险和配置隔离；构建前端。

约束：保留用户未提交修改；不部署、不触发真实订单；未知止损反馈时不得加仓。区域识别数据不绑定交易账户。
